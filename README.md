## What this repository is for

The name is a familiar one in this ecosystem, which is exactly why this page opens with a boundary. This repository is published by an account whose product is Terra Station Wallet. It is source code, it ships no installer, and it is not the place to start if your goal is a wallet holding LUNC or USTC.

A reader who followed a link expecting a framework homepage will find no feature tour here. That is deliberate. A page describing an implementation is written once and then read for months while the implementation moves, and the reader has no way to tell which sentences have expired. The repository's source, its commit history and its issue tracker are all maintained by the work itself, and this page is not going to compete with them.

What the page does instead is answer the questions a repository page can answer honestly: which account publishes this, what terms apply, what it is not, and where the reader who wanted the wallet should go. Four answers, all checkable, none of which will be wrong next month.

The account publishes one end-user product and three hubs of writing about it. This repository sits in the supporting source set, and its homepage field points at the application because that is what a visitor to this account usually wants. The guides then take over from there.

## How to approach this repository

1. Decide what you came for. Code, and you are in the right place; a wallet, and the application repository is one click away.
2. Read the licence before you plan a change. Apache-2.0 is recorded here, and its notice conditions are part of any reuse.
3. Read the source for behaviour rather than this page. A claim written here would be a claim nobody rechecks when the code moves.
4. Keep the dependency review narrow. Licence, maintenance history, default branch, and the issue tracker's tone answer most of it.
5. Leave the wallet questions to the hubs. They cover install, recovery and on-chain behaviour, and none of them assumes this repository.

## Common first questions

### Is this the wallet?

No. The wallet is a desktop application published from its own repository, with installers and checksums. This repository is source code published under its own terms and has no download for a reader to run.

### Which licence applies here?

Apache-2.0 as GitHub reports it for this repository, and the badge above names it without rewording. The licence file is the authority if the two ever disagree.

### Is this the same as every other repository with this name?

Each copy has its own owner and its own history, and this page speaks only for the one in this account. Check the owner in the URL before you rely on anything you read about the name.

### Where is the documentation?

The source and its commit history, plus the issue tracker for questions. This account spends its writing on the wallet's readers rather than on a second description of code that already exists.

## Before you depend on this

Confirm the licence, check how the repository has been maintained, and pin the branch you actually reviewed rather than assuming a default. Then read the source for the behaviour you need, because no page here will stand in for it.

If you arrived wanting the wallet, take the install hub instead. It opens with the file and its release, which is the only download path this account maintains.
